# Adult Games on Linux — Landscape (researched 8/27)

Tyler's ask pattern: **free**, character I control, has a story, wants *images* (not text-only). He'd already played Summertime Saga. "Thirsty + tired + just want to be absorbed" is the state to design for — pick zero-setup options first.

## Key gotchas

- **Itch.io delisted adult games from search results** (2025-ish). The store page + direct download links still work — you need the direct URL, not search. `team-monolith.itch.io/hometogether` is live.
- **UE5 games under Proton are hit-or-miss** — some boot fine, some crash instantly. For Home Together: download, unzip, Steam → Add a Non-Steam Game → force **Proton Experimental**. If it chokes, pivot to a native-Linux title (Night of Revenge) instead of fighting it — especially when Tyler's tired.
- **"Free" is a hard filter for him** on these — lead with the free tier, offer paid only as "if you want the story that's worth it."
- **Text-only ≠ what he wants on a depleted night.** He asked "does it have images too?" — check for visuals before recommending; prose games are a different mood.
- Third-party launcher wariness applies here too — prefer native builds or plain .exe + Proton over any launcher middleman.
